# 🚫 Telegram Banned (Termux/Linux/Windows)

পাইথন দিয়ে তৈরি একটি প্রিমিয়াম এবং শক্তিশালী টুল, যার মাধ্যমে খুব সহজেই যেকোনো টেলিগ্রাম অ্যাকাউন্ট বা নাম্বার **ব্যান (Banned)** করা যাবে। 

## ⚡ ফিচারসমূহ (Features)
- 🚀 **দ্রুত ও নির্ভুল সিস্টেম:** খুব দ্রুত টেলিগ্রাম অ্যাকাউন্ট চেক এবং ব্যান করতে সক্ষম।
- 🎨 **প্রিমিয়াম CLI ইন্টারফেস:** টার্মাক্সে ব্যবহারের জন্য সুন্দর এবং আকর্ষণীয় নিয়ন ডিজাইন।
- 📱 **মাল্টিপল নাম্বার সাপোর্ট:** একসাথে একাধিক নাম্বার রিপোর্ট করার সুবিধা।
- 🌐 **প্রক্সি সাপোর্ট:** ব্যান করার সময় আপনার আসল আইপি লুকানোর জন্য প্রক্সি (Proxy) যুক্ত করার অপশন রয়েছে।

## 📥 ইনস্টলেশন এবং ব্যবহার (Installation & Usage)

```bash

pkg install python -y

উইন্ডোজ / লিনাক্সের জন্য (For Windows / Linux)

cd telegram-banned
pip install -r requirements.txt
python main.py

## ⚙️ ব্যবহারের নিয়ম (How to Use)
১. টার্মাক্সে টুলটি রান করুন (`python main.py`)।
২. মেনু থেকে আপনার প্রয়োজনীয় **রিপোর্ট (Report)** অপশনটি সিলেক্ট করুন।
৩. টেলিগ্রাম **ইউজারনেম** (যেমন: `@Trojan`) দিন এবং এরপর ওই আইডির **Chat ID** প্রদান করুন।
৪. আপনি চাইলে **প্রক্সি (Proxy)** সেটআপ করে আপনার আসল আইপি হাইড করতে পারবেন।
৫. টুলটি স্বয়ংক্রিয়ভাবে রিপোর্ট প্রসেস করবে এবং প্রতিটি ধাপের লাইভ স্ট্যাটাস আপনার স্ক্রিনে দেখাবে।
